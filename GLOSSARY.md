# Grocery Helper

Grocery Helper is a single-account context for organizing grocery shopping into
named lists and the items that belong to them.

## Language

**Grocery list**:
A named collection of grocery items belonging to the account.
_Avoid_: Shopping group, item group

**List name**:
The human-readable label by which a person identifies a grocery list.
_Avoid_: List title

**Selected list**:
The grocery list currently in view and receiving the person's list or item
actions.
_Avoid_: Active list, current list
